# Sinkronisasi Excel lokal — rancangan sandbox untuk review

ADMIN dapat membaca `GET /sync/excel` (`file`, `lastSync`), menyimpan tujuan dengan `POST /sync/excel/config` (`file` absolut `.xlsx`), dan memperbarui laporan melalui `POST /sync/excel/run`. CASHIER ditolak 403. `GET /reports/excel-sales` menyediakan penjualan committed untuk ADMIN. Tidak ada perubahan skema SQLite.

File asing yang sudah ada saat pemeriksaan ditolak; file khusus POS dibuat saat sinkronisasi pertama dan ditulis ulang dari penjualan committed. Perubahan manual dapat tertimpa. File sementara dibuat di direktori tujuan sebelum penggantian; kegagalan dilaporkan tanpa menganggap sinkronisasi sukses. Excel adalah laporan, bukan backup SQLite. Pemilihan file dan pembukaan menggunakan Electron; browser biasa tidak menyediakan tombol ini. Isolasi sandbox dan lokasi konfigurasi lokal tetap berlaku. Rancangan ini belum merupakan persetujuan go-live.

**Risiko belum terselesaikan — ditunda setelah demo:** jika file asing muncul atau menggantikan file tujuan setelah pemeriksaan kepemilikan dan sebelum penggantian file sementara, `rename` dapat menimpanya. Risiko ini direproduksi dengan file sintetis dan belum diperbaiki; pemeriksaan ulang saja tidak menghilangkan perlombaan. Gunakan lokasi khusus laporan DEMO yang tidak dipakai proses atau pengguna lain sampai mekanisme penggantian bersyarat yang aman ditinjau dan diuji.
