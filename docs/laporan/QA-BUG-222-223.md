## Ringkasan Masalah dan Perbaikan

- **BUG-222 (Major)**: Tes periode Mingguan di `frontend/src/pages/DashboardPage.test.tsx` sebelumnya meng-hardcode tanggal `"2026-11-15"` dan rentang 9–16 Nov 2026. Diperbaiki dengan menurunkan tanggal hari Minggu minggu sebelumnya (`prevWeekSunday`) beserta batas `startMs`/`endMs` dan ekspektasi CSV langsung dari `now` (`new Date()`), sehingga tes tetap valid kapan pun dijalankan.
- **BUG-223 (Minor)**: `today` di `frontend/src/pages/DashboardPage.tsx` sebelumnya hanya dihitung sekali saat render, sehingga atribut `max` pada input tanggal dan judul omzet (`Omzet hari ini` / `Omzet minggu ini`) tidak terbarui bila halaman idle melewati tengah malam. Diperbaiki dengan menyimpan `today` di state React, menjadwalkan pembaruan pada tengah malam lokal berikutnya lewat operasi tanggal kalender (`new Date(now.getFullYear(), now.getMonth(), now.getDate() + 1)`), memperbarui saat window `focus` / `visibilitychange` kembali aktif, dan membersihkan timer serta listener saat unmount. Menambahkan unit test `BUG-223` di `frontend/src/pages/DashboardPage.test.tsx` dengan `vi.useFakeTimers()`.
